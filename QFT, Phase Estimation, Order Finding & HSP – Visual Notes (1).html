🔐 1. Hook: A Huge Lock, a Tiny Key

Imagine a giant lock: N = p × q (the product of two huge prime numbers). The internet's RSA (online security system) relies on this, because recovering p and q from N takes a classical computer years. Tiny example: N = 15 → 3 × 5.

🗝️ Shor's trick: turn factoring into finding a period (ax mod N repeats in a pattern). Finding a period is a job for the Fourier Transform, and a quantum computer does it very fast (QFT). This gives the whole chain:

🪙 Qubit and Measurement

A bit is only 0 or 1. A qubit is a mixture of 0 and 1 (superposition): |ψ⟩ = α|0⟩ + β|1⟩. When measured you get just one result (collapse): probability of 0 = |α|².

🕰️ Complex numbers = clock hands, and Roots of Unity

A complex number a+bi is an arrow: length = magnitude, angle = phase. eiθ = cosθ + i·sinθ is a point on the unit circle. Split the circle into N equal parts to get the N roots of unity (powers of ω = e2πi/N). This is the real language of the QFT.

👥 Group, Subgroup, Coset

A group = things + an operation that stays inside the set (e.g. Z12: adding on a clock). A subgroup = a smaller group inside (0,4,8). A coset = a shifted copy of the subgroup (1,5,9). Cosets split the elements into "families". See Section 8.

🌊 3 & 4. QFT and Inverse QFT

The classical DFT breaks a signal into frequencies (like separating bass and treble in a song). The QFT does the same on the amplitudes of a quantum state, using only n qubits (N = 2n).

QFT|j⟩ = (1/√N) Σk ωjk |k⟩, ω = e2πi/N
• j = input number • k = output frequency • 1/√N = normalisation • ωjk = rotating hand. Inverse QFT: just replace ω by ω−1 (negative phases, gates in reverse order).
How to read: each qubit gets an H (superposition), then controlled phase rotations Rk from the lower qubits (rotate the phase by 2π/2k), and finally a SWAP (the bit order comes out reversed, so flip it back).

🎯 5. Phase Estimation (QPE)

Problem: given an eigenstate |u⟩ of a unitary U (a quantum operation): U|u⟩ = e2πiφ|u⟩. Find φ (between 0 and 1).
Phase kickback: applying controlled-U leaves |u⟩ unchanged, but the phase gets "kicked back" onto the control qubit. Apply U2^k from counting qubit k and the phase 2kφ accumulates → this forms a Fourier state → read φ directly with the inverse QFT.

How to read: counting qubits on top (start with H), |u⟩ at the bottom. Controlled-U2^k in the middle, then QFT⁻¹ and measurement → binary φ.

🔁 6. Period Finding

f(x) = ax mod N repeats. The quantum way: superposition of x → compute f(x) → measure the second register (now only x₀, x₀+r, x₀+2r... remain) → QFT → peaks at k ≈ jQ/r.

f(x) = aˣ mod N (x = 0..63)QFT output |amplitude|² (Q = 64)
How to read: the top wave repeats every r steps. The bottom peaks are evenly spaced, and that spacing reveals the period. Continued fractions turn a peak k/Q into the nearest simple fraction s/r (r = denominator).

🧩 7. Order Finding Problem

The order is the smallest r > 0 with ar ≡ 1 (mod N) (needs gcd(a,N)=1). Link to QPE: U|y⟩ = |ay mod N⟩ is a unitary whose eigenvalues are e2πi s/r. Get s/r from QPE → you have r!
⏱️ Classical: best algorithms ~ exp(n1/3) (subexponential). Quantum (Shor): ~ O(n³) (polynomial) → far faster.

Shor flow: N → pick a → order r (quantum) → r even? → x = ar/2 mod N, x≢−1 → gcd(x−1,N), gcd(x+1,N) = factors 🎉

🧬 8. Hidden Subgroup Problem (HSP)

A function f on a group G is constant on each coset and different on different cosets. Find the hidden subgroup H. A big family: Simon's problem (G=Z₂ⁿ), Period/Order finding (G=Z), Discrete log (G=Z²) are all special cases.

Flow: superposition → evaluate f → QFT over G → measure → classical post-processing (recover H from the samples).
G = ZN, N: H = ⟨d⟩, d:
How to read: each circle is a group element; same colour = same coset (same f value). Each sample gives a k with k·d ≡ 0 (mod N). The gcd of a few samples with N gives d = N/gcd.

Non-abelian groups (e.g. dihedral DN, symmetric Sn): the order of operations matters, so the simple QFT approach fails. Dihedral HSP ≈ lattice problems (post-quantum crypto) and Sn HSP ≈ Graph Isomorphism; both are still open.

⚠️ 11. Common Mistakes

QFT ≠ classical FFT: the QFT transforms amplitudes, but you cannot read all amplitudes; you can only measure.
Forgetting the final SWAP (bit reversal) in the QFT circuit reverses the output.
If the period r is odd, or ar/2 ≡ −1 (mod N) → pick a new a and retry.
gcd(a, N) = 1 is required; otherwise ax mod N never reaches 1 (but then the gcd itself is a factor!).

✅ 14. Summary

1) QFT turns amplitudes into "frequencies". 2) The inverse QFT undoes it. 3) QPE finds the phase φ (phase kickback + QFT⁻¹). 4) In period finding, QFT peaks reveal r. 5) Order finding = QPE on U|y⟩=|ay mod N⟩. 6) Order → gcd → factors (Shor). 7) HSP covers all of these; the non-abelian case is open.
